# KQ Magazine — Kraig Quarterly

A flip-through browser magazine: affectionate NSFW roast of **Kraig** (writer *and* subject). Vite + React + TypeScript.

## Quick start

```bash
cd /workspace/kq-magazine
npm install
npm run dev
```

## Deploy free on Vercel

1. Import https://github.com/2squirrelsai/kq-magazine on vercel.com (Hobby plan is free).
2. Framework: Vite · Build: `npm run build` · Output: `dist`.
3. `vercel.json` is already in the repo.

## Production build

```bash
npm install
npm run build
npm run preview
```
